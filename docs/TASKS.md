Binds T08 (resume must keep the counts consistent) and T16 (real-corpus run record).
- **T07 — chunk_hash normalization binding for T08:** normalized body = LF lines with per-line trailing and outer whitespace stripped; body/url/heading NUL-joined before SHA-256 (`chunk_hash` docstring). §7.4 updated in this PR — T06's recorded deviation below is paid off here.
- **T07 — embedding boundary with T08:** inserted chunks embed in batches of ≤100 via `backend.embed_documents`; the bounded 429 backoff is the backends' own (`call_with_backoff` wraps every embed call inside providers, T04) — deliberately NOT re-wrapped in ingest. Only inserted chunks are embedded; repairing chunks left without vectors by an interrupted run is T08's checkpoint/resume scope. All writes commit once at the end (a crash leaves the previous complete state; T08 splits this with per-batch checkpoints).
- **T07 — `ingest_runs` lifecycle:** `upsert_ingest_run` + `finish_ingest_run` run at completion (§10.3's final step), so a crashed ingest leaves the prior completed row for the fingerprint intact; `started_at`/`finished_at` span the actual run.

Binds T07 (chunk bounds), T16 (real-corpus chunk counts), and all token-bound tests. ✅ Deviation from §14.4 paid off in T07's PR: §7.4 now names the estimator.
- **T06 — cap mechanics:** every chunk ≤ 1,900 tokens (`MAX_CHUNK_TOKENS`); split, never truncated. Heading unit: H2-boundary groups (H3+ attach to their H2; intro under the title is its own group), greedy neighbor merge up to `size_tokens`; a single section > `size_tokens` is emitted alone and whole up to the cap (the §14.2 "single section exceeds it" exception); only beyond 1,900 is it split into sequential whitespace-aligned windows of ≤ `min(size_tokens, 1900)` tokens, no overlap. Fixed unit: window body budget = `size_tokens` − prefix tokens (prefix counted), advance = window length − `overlap_tokens`; cuts prefer the latest line/whitespace break, hard cuts last resort.
- **T06 — public API frozen for T07:** `parse_page(rel_path, text) -> ParsedPage` (`rel_path`, `page_url` via T05's `page_to_url`, `title` = first ATX H1, `segments: list[BodySegment]`); `BodySegment(heading_path, level, body)`; `ParseError(rel_path, reason="no H1")`; `Chunk(page_url, heading_path, body, body_tokens, ordinal)` (field order mirrors `db.ChunkRow` minus chunk_hash — T07 builds rows positionally); `Chunker` Protocol with `chunk_page(page) -> list[Chunk]`; `make_chunker(cfg)`; `count_tokens`. parse.py does no file I/O — T07 owns reads + the tarball top-dir strip. - **T06 — micro-decisions documented in module docstrings:** H4+ headings extend the heading-path pattern (not truncated at H3); fixed-window chunk heading path = path as of the window's first character; heading unit ignores `overlap_tokens` (warning logged if set > 0).
